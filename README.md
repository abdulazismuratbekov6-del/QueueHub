# QueueHub

SaaS-сервис для управления живыми очередями студентов на лабораторных, экзаменах и зачётах.
Заменяет бумажные списки и переписки в мессенджерах: преподаватель создаёт очередь, студенты
присоединяются по ссылке, QR-коду или коду комнаты, всё обновляется в реальном времени.

## Стек

- **Frontend**: Next.js 14 (App Router), TypeScript, Tailwind CSS, Zustand, React Query, Socket.IO client
- **Backend**: NestJS, Prisma ORM, PostgreSQL, Socket.IO, JWT-аутентификация
- **Монорепо**: pnpm workspaces (`apps/web`, `apps/api`, `packages/shared`)

## Структура

```
apps/
  web/      Next.js фронтенд
  api/      NestJS бэкенд + Prisma schema
packages/
  shared/   общие TypeScript-типы и enum'ы для web и api
```

## Запуск в разработке

### 1. Требования

- Node.js >= 18.18
- pnpm (`npm install -g pnpm`)
- Локальный PostgreSQL

### 2. Установка

```bash
pnpm install
```

### 3. Переменные окружения

Скопируйте `.env.example` в `apps/api/.env` (и при необходимости `apps/web/.env.local`)
и укажите свою строку подключения к PostgreSQL в `DATABASE_URL`.

### 4. База данных

```bash
pnpm --filter @queuehub/api run prisma:migrate
```

### 5. Сборка общего пакета типов

```bash
pnpm --filter @queuehub/shared run build
```

### 6. Запуск

В двух терминалах:

```bash
pnpm run dev:api   # http://localhost:4000
pnpm run dev:web   # http://localhost:3000
```

## Реализованный функционал MVP

- Создание/редактирование/открытие/закрытие очереди преподавателем
- Вход по ссылке, QR-коду и коду комнаты (гость — без регистрации, если это разрешено)
- Автоматическая и случайная очередь
- Обмен местами: временный ("один круг", с автоматическим возвратом) и постоянный
- Таймер с автоматическим вызовом следующего студента
- История действий и статистика по очереди
- Поиск участника по имени/фамилии
- Фото профиля: камера, галерея, загрузка файла
- Обновление очереди в реальном времени через WebSocket (Socket.IO)
- Уведомления в браузере о приближении очереди
- Экспорт очереди в PDF и Excel
- Светлая/тёмная тема, адаптивная вёрстка
